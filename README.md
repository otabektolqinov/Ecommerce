# 🛒 E-Commerce Platform

This is a **Java Spring Boot E-Commerce application** built as a portfolio project.  
It includes both a **REST API** for modern frontend integration and a simple **Admin Panel** (Spring MVC + Thymeleaf) for managing users, products, categories, sellers, and orders.

## 🚀 Features

### REST API
- CRUD operations for:
    - Products
    - ProductFiles
    - Comments
    - CommentFiles
    - Categories
    - Addresses
    - Payments
    - Sellers
    - SellerLogos
    - Orders
    - CartItems
    - Users
- Search and filtering (by name, category, etc.)
- Pagination & sorting
- Exception handling with global error responses
- DTO-based architecture
- Ready for integration with frontend frameworks (React, Angular, Vue)

### Admin Panel (MVC)
- Simple admin dashboard (Thymeleaf + HTMX + Bootstrap)
- Manage users, products, categories, sellers, and orders
- Search and filter products by name or category
- Edit and delete entities
- User-friendly interface for demo purposes

---

## 🛠️ Tech Stack

- **Backend**: Java 21, Spring Boot
- **Database**: PostgreSQL (JPA/Hibernate)
- **Frontend (Admin Panel)**: Thymeleaf, HTMX, Bootstrap
- **Build Tool**: Maven
- **Others**: Lombok, Validation API
